## Problem

Modern desktop environments accumulate background services, duplicate tools, hidden state and workflow friction.

## System

ARCHMAC is an opinionated sovereign workstation built around Arch Linux, a tiled Wayland environment, terminal-first tooling, reproducible configuration and explicit operating doctrine.

## Engineering principle

Reduce the distance between intent and execution while preserving inspectability, rollback and control.
