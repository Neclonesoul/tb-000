## Objective

Teach a complete field-computing progression using equipment that can travel: an Android device, terminal tools and progressively more capable physical systems.

## Constraint

The curriculum begins with mobile hardware and assumes the learner should be able to publish and diagnose without a conventional development workstation.

## System

The learning path is arranged in four levels. Each level establishes the tools needed by the next.

01 — Pocket Terminal  
02 — Publish From Anywhere  
03 — Field Diagnostics  
04 — Physical Computing

## Build

The material connects Android terminal work, Git-based publishing, network diagnostics and microcontroller-oriented physical computing.

## Result

The public site and repository provide a structured curriculum rather than a loose collection of commands.
